# Review organized by setting

Review now groups pending interpretations by project, source and suggested setting: Class & learning, Meeting, Conversation, Personal, or Context needs sorting. Groups follow their first occurrence in the source; items within each group follow their original evidence offsets. This replaces creation/hash ordering. Multi-group reviews are collapsed so the user can choose one context at a time.

New AI extraction asks for the local setting of each claim, rather than treating an all-day recording as one event. The category is stored separately from the evidence claim, cannot identify the wearer, and does not establish participation, ownership or accepted work. Legacy/unclassified items remain visibly unsorted. No historical review decisions are reset. The optional organizer can apply evidence-checked context labels to pending items only with explicit Meta consent; it is not an extra automatic cloud upload.

Reference notes with valid evidence can be kept together after the user checks that they reviewed the displayed group. The server accepts at most 100 explicit IDs, all still pending reference claims in one project/source. It validates the whole selection inside one transaction. A work claim, invalid evidence, already-reviewed ID or cross-source selection rejects the whole group. Decisions, commitments and deliverables remain individual reviews. Group actions never send, publish or create a work obligation.

An in-progress worker keeps its loaded prompt until it finishes. Context labels appear on new readings after the updated service starts; older items are not silently reclassified.


## Daily class lesson review (November 3)

Pending class reference passages now form one daily lesson outline per selected project and recording. Topics are sections inside that lesson, not separate top-level reviews. The reviewer names the class period and explicitly confirms the displayed membership. Expand the evidence area to inspect exact quotes, reject individual points or correct interpretations. Non-class conversations remain outside the lesson.

Possible assignments, exams, submissions, deadlines, dated items, non-reference claims and evidence-blocked items stay in individual review and are excluded from Keep daily lesson. Keyword routing is a conservative convenience, not proof of an assignment and not a complete detector. The title and source remain visible; the user must check membership. Multiple class periods inside one recording are not automatically segmented yet; do not confirm them as one period.

Keep daily lesson atomically reviews only its explicit pending learning IDs and saves one editable local note with all source spans. No personal work is accepted. The note appears in Notes, can be amended/downloaded, and requires separate approval before Notion publishing. This is an extractive outline of existing interpretations, not a fresh model synthesis or independent fact check. Existing accepted/rejected reviews are preserved; the sidebar count still reports underlying pending evidence items.
