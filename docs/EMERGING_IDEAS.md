# Emerging ideas

Available from an imported source under **Explore an emerging idea**. Explicit consent sends the selected source, project name and up to 20 current reviewed project memories to Meta Muse Spark 1.3. Memory values are limited to 1,200 characters and subjects to 200; full local evidence is retained. No other project's memory is included. Automatic Bee reading remains local.

Ideas are stored separately from work claims. Each has an exact, distinctive source quote and offsets, possible relevance, an optional exploration step, and validated links to supplied reviewed memory. Speaker identity remains unconfirmed. Keep and Dismiss are local review choices; neither establishes decisions, assignments, deadlines or external actions.

The reader processes every source section through the existing background queue. It saves validated ideas as sections complete, preserves reviews on retries, and reports failed validation or incomplete sections. Ideas and their connections are snapshots at reading time; they are not automatically updated as project memory changes. Model interpretations still need human review, including whether the quote actually supports the idea and who expressed it.

Current limits: discovery is manually initiated per source; no automatic idea routing, semantic deduplication across different quotes, exploration-note generation or connected-service delivery. Kept ideas are accessible on their original source. No psychological or personality inference is intended.

Validation: four dedicated tests cover consent before extraction, exact evidence, invalid memory links, uncertain identity, retry deduplication and separation from work. Full suite: 158 tests passing. Real Meta evaluations use synthetic text only; see the dated evaluation artifact in the build chat outputs.
