# What changed?

Mission Control includes a collapsed **What changed?** section on each project. The newest five entries load first, with Show more for the remaining entries. Each comparison is collapsed individually.

- Reviewed revision: follows an explicit accepted claim's `supersedes` link to the prior claim. Shows both positions and their exact supporting source passages. Historical revisions remain visible even after later revisions.
- Proposed comparison: shows a pending interpretation against the current reviewed position with the same kind and normalized subject. Topic matching is only a comparison aid. It does not infer agreement, supersession or a semantic difference.
- New proposal: no current reviewed position matches that topic. This does not imply an assignment or decision has been established.

Conflicting current positions appear together rather than selecting one as authoritative. Attribution, ownership, work status and date confidence remain visible. Ambient and uncertain evidence remains blocked from establishing project work. Open source returns to the original record; Review suggestion opens the existing source-filtered review queue.

Reference learning, rejected claims and emerging ideas stay outside this work comparison. This is a read-only view over existing evidence and reviews, not a full daily activity log. It makes no network inference calls and changes no project state. Accepted claims without explicit supersession do not appear as reviewed replacements.

Validation: tests verify pending interpretations do not change current state, explicit replacement is required, conflicts retain both positions, and rejected/reference claims are excluded. Full suite: 161 tests passing. Browser verification used an isolated synthetic workspace.
